# Repeat and chromosome-end evaluation — planned

Objectives: centromeric satellites, telomeric motifs and terminal completeness, tandem repeats, segmental duplications and repeat copy representation. No completed systematic repeat annotation is claimed for the current assemblies.

Proposed evidence: annotate motifs/repeats with explicit versions and parameters; compare assemblies in assembly coordinates; combine unique flanks, long spanning ONT/HiFi reads and read-kmer multiplicity. Separate biological variation, mapping ambiguity and true collapse/expansion. Compare chromosome ends without assuming reference-relative unalignment is missing sequence.

Before execution, agree methods and SLURM resources. Preserve originals and record repeat-model/reference provenance. This directory contains planning documentation, not executed results.
