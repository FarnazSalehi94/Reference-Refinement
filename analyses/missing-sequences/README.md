# Missing/collapsed sequence — planned evidence integration

Candidates may be reference-present/assembly-unaligned, supported read-kmers absent from an assembly, or suspicious repeat copy representation. These are different signals and must not be merged into a confirmed missing-DNA list without validation.

For each candidate record original assembly and reference coordinates, alignment confidence, reference gaps/repeat context, sample provenance, read depth and uniquely anchored spanning reads. Distinguish insertion/deletion variation, repeat ambiguity, contamination and genuine assembly omission. Read-kmer completeness is not base-level completeness.

Use completed reference tables and existing Merqury outputs before expensive new read mapping. No finalized missing-genome intervals or adaptive-sampling targets have been established here.
